### Elec Club MakerFest Session-1: Pong Game

This repo contains a simple implementation of Pong Game for running in ESP32. 

Files for Wokwi simulation are also provided : `wokwi.toml`, `diagram.json` and `platformio.ini`. 

The source files are in 6 levels, slowly building up to the full game, for teaching purposes (more details in that directory).

This repo was used to teach game development in ESP-32 in MakerFest, organized by Electronics Club, Centre for Innovation (CFI), IIT Madras
